# Portfolio engineering handoff

Start a fresh agent session. Read this file and PROGRESS.md, then verify current GitHub state. Do not resume a large unrelated project conversation or paste a historical master prompt.

1. Verify the authenticated account. Check unread notifications, open authored PR reviews and exact-head CI. Network errors are not proof of invalid credentials; never disable TLS verification.
2. Prioritize maintainer feedback and CI failures, then unfinished original finance, quant and engineering work. Check existing branches and PRs before creating work. Never manufacture duplicate contributions.
3. Read repository instructions and inspect status before editing. Preserve existing changes; isolate independent work in separate worktrees. Use reviewers only when useful.
4. Implement one bounded improvement, run focused tests, review the diff, commit intended files, push a work branch and inspect CI for that exact SHA. Do not merge or sign legal declarations by default.
5. Validate mathematics, units and assumptions independently for financial code. Do not change licensing without the owner's decision.
6. Record date, issue/PR, branch/SHA, actual tests, CI status and next step. Archive long history outside the active checkpoint. End the unit with a saved handoff; start the next unit fresh.

The local free-provider gateway is separate from GitHub's Claude OAuth workflows. Route names are not a promise of free Anthropic models. Do not introduce paid fallback, copy credentials into repositories or activate paid workflows to bypass a configuration failure.
